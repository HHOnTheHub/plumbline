# Obligations library

The Bermuda laws, BMA codes and guidance that bind how apps are built and run. Each file is one instrument, with permanent requirement ids (`OBL-PIPA.3`). Clauses in [../standard/clauses.md](../standard/clauses.md) cite these ids in their Answers column, and each entity's obligations register (GOV-7) cites them instead of restating the law.

**Status: every entry is unverified** (Plumbline v0.5.0, Oct 19, 2026). They were drafted from the Bermuda Hard-Boundaries Register, a research map, and are not legal advice. An entry becomes verified only when counsel confirms it against the consolidated text and the entity's CRCO records how it applies.

| Change | Proposed by | Checked by | Approved or noted by |
| --- | --- | --- | --- |
| Add or change an entry | An entity's CRCO, or the nightly run as a proposal only | Counsel | the maintainer accepts into Plumbline; each board notes it |
| Mark an entry verified | Counsel | | The CRCO records it; the board pack shows the status |
| Change how an entry applies to one entity | That entity's CRCO | Counsel | That entity's board, through its technology policy |

Corporate, tax, employment and immigration instruments are not here; they belong in each entity's own obligations register. Dates to watch are in [watch-list.md](watch-list.md).
