# Propose a Plumbline change

1. Find Plumbline: a local checkout, or https://github.com/HHOnTheHub/plumbline at the version named in this app's `CLAUDE.md`, and read `standard/clauses.md` and `CHANGELOG.md`.
2. Write the proposal as `<YYYY-MM-DD>-<short-name>.md` in the operator's private proposals folder (or, for a change useful to everyone, as an issue or pull request on the Plumbline repository, with anything identifying removed). It holds:
   - **Change:** the clause text as it is and as proposed, or a new clause with a proposed id (never reuse a retired id).
   - **Why:** what happened in which app, with file paths.
   - **Impact:** which apps would have a new gap, and roughly how much work.
   - **Version:** patch (wording), minor (new clause or sharper check) or major (changed or removed obligation, needs each board).
3. Do not edit the standard, the clauses, AUTONOMY.md or RUN.md. The maintainer decides.
4. Tell the user the proposal's path in one line.
