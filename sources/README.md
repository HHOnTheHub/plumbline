# Practice sources

Recognised standards and thinkers that inform Plumbline as they evolve. **These are advice, not law.** The law is in [../obligations/](../obligations/).

## Rules

| Rule | |
| --- | --- |
| What a source can do | Produce proposals only. It never adds a requirement by being read |
| How clauses cite it | `practice: SRC-…` in the Answers column, never an `OBL-` id, so the board sees law, recognised standard and own choice apart |
| Cadence | Reviewed in the nightly run's first run of each quarter: has a new version been published? |
| Limit | At most three source-driven proposals a quarter |
| The test for a proposal | It cites the specific passage **and** names a gap in a real app it would close. A proposal with no gap is declined |
| Adding or removing a source | A proposal the maintainer decides |
